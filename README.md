# AI SEO Blog & Content Cluster Generator for Bright Future Academy

## Project Overview

This project contains a structured SEO content workflow designed for Bright Future Academy, Vijayawada. The objective is to create ranking-focused content systems that improve search visibility, build topical authority, and generate student admissions through organic search traffic.

## Business Information

**Business Name:** Bright Future Academy

**Location:** Vijayawada, Andhra Pradesh

**Services:**

* IIT JEE Coaching
* NEET Coaching
* EAMCET Coaching
* Foundation Courses

## Deliverables

### 1. Pillar Blog Prompt

A long-form SEO article targeting the primary keyword:

* Best IIT JEE, NEET & EAMCET Coaching Institute in Vijayawada

### 2. Supporting Blogs (Content Cluster)

Supporting blog prompts covering:

* FAQs
* Service-specific topics
* Location-based searches
* Problem-specific searches

### 3. SEO Blog Structure Prompt

A prompt that generates:

* SEO-friendly H1–H3 headings
* Internal linking suggestions
* Clear content structure
* Business-focused conclusions

### 4. Local SEO Adaptation Prompt

A prompt designed to:

* Target service + location keywords
* Attract local search traffic
* Improve local search visibility in Vijayawada
